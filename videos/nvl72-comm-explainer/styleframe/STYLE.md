# Styleframe：机房暗场 · 铜与光

大模型通信科普片（GB200 NVL72）。纯 HTML/CSS/SVG 静态关键帧，用于确认视觉语言，
不代表缓动与运镜。`./shoot.sh` 用无头 Chrome 截出 `out/*.png`（首次运行会下载 Noto Sans SC）。

## 视觉主张

暗色机房里，铜代表物理连接，青绿代表正在流动的数据。全片只有这两种强调色，
网络（跨柜、慢路径）一律用灰，速度差靠颜色亮度直接读出。

## Tokens（见 `tokens.css`）

| 角色 | 值 | 用途 |
|---|---|---|
| 底色 | `#0a0c0e` + 48px 网格（4.5% 白） | 全片地面 |
| 正文 / 次级 / 纹理 | `#eceef0` / `#a2abb5` / `#5d6772` | 三级文字 |
| 铜 | `#d98a52`，高光 `#f4b781` | NVLink、铜缆、GPU、关键数字 |
| 信号青 | `#43e0b5` | 数据包、交换芯片、SHARP、全域带宽 |
| 慢路径灰 | `#4a525b` | 400G 网络、跨柜 |
| 中文 | Noto Sans SC 400/500/800/900 | 标题、字幕 |
| 数字 / 英文术语 | JetBrains Mono 700/800 | 带宽、耗时、公式 |

字号：字幕 56px，辅助文字 ≥32px，32px 以下只作纹理（Q11）。
光效：只给数据包和主角 GPU 加辉光，不群发（Q4）。

## 动效性格（待动态测试确认）

能量低到中、调性严肃，从“专业信赖”预设起步：主时长约 21f@30fps，入场
`bezier(0,0,0.2,1)`，信息动作不过冲；只有数据包到达、数字砸落这类有落地隐喻的
动作允许 1.04 的轻过冲。关键数字落定后 hold ≥1s。

## 关键帧

1. `frame-01-opening`：开场，铜缆脊柱 + 主标题
2. `frame-02-anatomy`：拆开 NVL72，1 块 GPU 的 18 条 NVLink 连向 18 颗交换芯片
3. `frame-03-cost`：Ring AllReduce 示意 + α–β 模型 + 三档耗时对比（理想值）
