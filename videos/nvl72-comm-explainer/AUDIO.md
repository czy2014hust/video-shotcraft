# 音频

这支片子不配 BGM。仓库里的五首备选都是强鼓点 House / Hip-hop，配上就必须全片卡点，
会把讲解需要的停留挤掉。画面按「低频、不卡点」的方向做，所以只留动作拟音。
因此不交付无 BGM 的第二版：成片本身就没有音乐轨。

## 音效

全部 CC0，Freesound 高质量 MP3 预览（不是上传者的原始 WAV）。来源、哈希和分析在
`public/audio/sfx/audio-manifest.json` 和 `FREESOUND-CREDITS.md`。

选材时听过预览描述和测量，没有把合成 UI 提示音放进来。成片里的听感以渲后为准。

## 对齐

钉点公式：`from = round(目标帧 − 音源能量峰帧 − 输出偏移帧)`。

音源能量峰（10 ms RMS，不是 LUFS）来自下载时的分析：

- fs-755054：0.215 s → 6.45 帧
- fs-406559：0.005 s → 0.15 帧
- fs-427823：0.215 s → 6.45 帧
- fs-59989：0.045 s → 1.35 帧

输出偏移按这条管线实测：Remotion 4.0.484、h264/aac、48 kHz、mp4。
2026-11-13 用开场冲击做探针，目标帧 96，当时按 1.28 帧偏移排到第 88 帧起播，
渲出音轨的 10 ms 能量峰在第 95.4 帧，样本峰在第 94.4 帧。
反推输出滞后 0.95 帧，常数改成 `OUTPUT_AUDIO_OFFSET_F = 0.95`。
这次窗口里只有这一下尖锐冲击，没有第二支探针。
